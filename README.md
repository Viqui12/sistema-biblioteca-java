Sistema de Biblioteca
Projeto acadêmico desenvolvido em Java para praticar programação orientada á objetos.

Funcionalidades

.Cadastro de informações de livros.
.Registro de leitores com nome,matrícula e turma.
.Controle básico da disponibilidade dos livros.
.Registros das datas previstas e realizadas de devolução.


Tecnologias utilizadas

.Java Programação orientada á objetos
.Eclipse IDE

Estrutura do Projeto

.Livro.java: representa os livros e seus atributos.
.Leitor.java:representa os leitores.
.Emprestimo.java:reúne as informações de um empréstimo.
.Biblioteca.java:contém o método principal e a interação com o usuário pelo terminal.

Como executar 
1-Abra o projeto em uma IDE compatível com Java, como o Eclipse.
2-Execute a classe Biblioteca.java.
3-informe os dadOS Solicitados no terminal.

Sobre o projeto
Este projeto foi desenvolvido para fins de aprendizado e prática de conceitos de Java.Os dados são informados durante a execução e não são armazenados permanentemente em um banco de dados.
